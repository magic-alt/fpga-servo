# Local model provenance

`model_sources.json` identifies exact copied model bytes and their source library. Existing generic models remain generic; they are not exact manufacturer fit evidence. Original embedded copyright notices are unchanged; the accompanying `frozen-system-models-v1/LICENSE.md` retains the upstream library terms.

Orange `envelopes-v1` models are analytic clearance envelopes, explicitly NOT OEM models. Their dimensions, reserves and exclusions are in `envelopes-v1/envelope_manifest.json`. Actual seating, joints, mating housings, cables, screws, tools and enclosure fit remain unqualified.
