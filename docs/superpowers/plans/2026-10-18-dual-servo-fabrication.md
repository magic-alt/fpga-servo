# 双 ADC 方案工程首板实施计划

用户已确认：工程首板投板；两方案统一四层；嘉立创制造；24–48 V、
20 kHz、10 Arms 连续、20 A 峰值 30 秒、40°C 风冷、12 V 总连续 1 A；
不增加板载制动，电机测试必须采用经验证的外部吸能/钳位。

## 任务及完成条件

1. 保存两工程源快照和新鲜原生基线，纠正 README、索引及上电文档的旧状态。
2. 按功能块审核全部板载器件、物理引脚、封装、容差/降额和故障状态；
   统一 1 A 辅助电源。电气 ECO 显式列出物理网络差异，纯图面调整保持网表等价。
3. 冻结可制造的四层叠构和 DFM 规则。ADS8588S 原生同步重建；
   AD7606C 复审现有铜路。保留板框、孔位与接口锚点，关键功率/安全网络不自动布线。
4. 在统一工具内增加 prototype 验证及 fabrication 导出，保持 release 的完整实物门禁；
   为缺失证据、源漂移、错误引脚/封装、Kelvin 和禁用检查建立负向回归。
5. 两工程分别执行原理图、完整回归、ERC、补铜后全严重度 DRC、物理一致性、
   原生几何和逐页/逐层视觉检查。闭合首板前设计/制造问题后导出并独立检查制造包。

## 验收

ERC 0 errors / 0 warnings / 0 exclusions；DRC 0 violations / 0 unconnected /
0 schematic parity；器件/封装、关键回路、电流与热预算、实际工艺和制造包审核通过。
未完成台架试验保持 NOT_RUN，不能通过放宽检查、伪造签名或填写计算值关闭。
峰值重复周期、最小风量和实际编码器负载尚未固定，额定运行不能据本轮 CAD 结果放行。

默认制造目标：四层 1.6 mm、外层 2 oz/内层 1 oz、FR4 Tg170、绿油沉金、常规通孔。
实际可下单叠构编号及介质参数必须核实后冻结，不以这一目标代替制造证据。

实施核实更新（2026-10-19）：公开 JLC041621-3313 实际为 NP-155F/Tg155，
并非上述初始 Tg170 目标。当前仅按此真实四层叠构建立工程候选，90°C 热点预算及
台架温升仍待审核。功率焊盘下通孔拟选付费四层 TypeVII 环氧填孔、磨平、铜盖孔工艺；
J1/J5 与 J4 分别要求1.02±0.05mm、1.85±0.05mm成品孔。供应商工艺接受和人工制造审核
未完成，不能因候选已写入 CAD 就认为已具备普通工艺下单条件。

## 接口及回归要求

计划入口：`verify --scope prototype`、`export --kind fabrication`。
prototype_ready 与 pcb_release 独立记录；设计/制造证据缺失不能返回首板通过。
所有制造文件来自同一冻结源；最终记录 SHA、工具版本、命令、原始报告和输出哈希。
源码保持两个独立工程；ADS8588S 双 DOUT、AD7606C 四 DOUT/SDI 及各自 ADC 配置保留。
