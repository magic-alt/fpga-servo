## 修改范围

原TPS3808G50监控门限可能低于ADS8588S的4.75V最低工作电压；仅调高监控门限又会与原固定5V稳压器的最坏输出重叠。因此同时修改5V稳压和独立监控，不依赖FPGA或ADC软件判断。

| 位号 | 新器件/设定 | 作用 |
| --- | --- | --- |
| U13 | TPS62901RPJR；外部分压；MODE=VIN | VA_5V标称5.1V，强制PWM 2.5MHz，VOS接实际输出 |
| R94/R95 | 75k/10k | 0.6×(1+75/10)=5.1V |
| U25 | TPS389001DSER；VDD由VIO供电 | 独立监测VA5，欠压拉低共用POR_N |
| R92/R93 | 3.24k/1k | 1.15×(1+3.24)=4.876V标称下降门限 |
| C94 | 100nF | 恢复延迟约107ms标称；不延迟欠压断言 |

四只分压电阻均采用Susumu RG1608N，0603，±0.05%，±10ppm/°C：R92=`RG1608N-3241-W-T5`，R93=`RG1608N-102-W-T5`，R94=`RG1608N-753-W-T5`，R95=`RG1608N-103-W-T5`。厂商目录中的5ppm V档不覆盖全部阻值，故未使用该档。0.1%寿命漂移是本项目计算分配，仍需按实际温度、工作寿命、批次和装配确认，不能理解为任意使用条件下的保证。BOM已重新导出；禁止用普通1%电阻替代。

## 实际封装脚序及禁止链

U13 RPJ0009A：1 PG→PWR_GOOD；2 SW→L2.1；3 VOS→VA5；4 GND；5 EN→VDRV12；6 VIN→VDRV12；7 MODE→VDRV12；8 SS/TR按数据手册允许开路使用内部软启动；9 FB→R94.2/R95.1。

U25 DSE0006A：1 SENSE→R92.2/R93.1；2 GND；3 MR→VIO；4 VDD→VIO和C91；5 CT→C94；6开漏RESET→POR_N。不能复用旧TPS3808脚序。

欠压使POR_N为低，经U26施密特缓冲、U23健康条件与门，使U20异步CLR有效，ARMED清零；U11 RUN_OK变低后六路PWM被禁止。电源恢复只解除复位，不会自行设置ARMED；仍要求健康条件、GATE_EN低和新的FAULT_CLEAR上升沿。VIO失电及部分供电的模拟行为仍需独立验收。

新增两种项目本地封装按TI推荐焊盘图绘制：RPJ0009A图4224505/A，DSE0006A图4220552/B。DSE 1–3脚阻焊收缩0.05mm形成SMD焊盘，4–6脚扩展0.05mm形成NSMD。铜焊盘几何及脚号已独立复核；钢网、板厂阻焊能力和装配验证仍未放行。

## 静态最坏情况计算

使用TPS3890参考1.15V±1%、SENSE漏电±100nA、迟滞上限0.825%；TPS62901外部FB参考0.6V±0.9%、FB漏电±70nA。每只电阻独立使用±0.25%界限：初始0.05% + 100°C温差×10ppm/°C=0.1% + 漂移分配0.1%。穷举参考、电阻及漏电的所有边界组合。

| 参数 | 当前结果 |
| --- | --- |
| 下降触发门限 | 4.808519–4.943948V |
| 最高恢复门限 | 4.984736V |
| 稳压静态输出范围 | 5.026621–5.173923V |
| 最低触发点至ADC 4.75V下限 | 58.519mV |
| 计入假设10mV负纹波后的恢复余量 | 31.885mV |
| 计入假设10mV正纹波后至5.25V上限 | 66.077mV |

10mV是设计预算，**不是测量结果**，也不覆盖负载突变过冲。静态门限余量无法保证任意陡峭掉电过程中先关PWM再退出ADC工作区。TPS3890的18µs是特定过驱条件下典型值，数据手册未提供可直接采用的最坏上限；禁止据此关闭快速掉电验收项。

VA5仍是共用电源。INA241零电流中心改为约2.55V；比较器标称上下阈值改为0.3000/4.8000V，对5mΩ、20V/V为约±22.5A。校准、ADC输入余量和实际编码器5V容差必须按新电源范围复核。OCP误差、桥臂故障覆盖及热设计未因此关闭。

## 尚需关闭的验收条件

1. 在实际温度/负载/输入范围内测VA5纹波、启动和负载瞬态；验证C31有效容量、L2饱和/纹波、强制PWM下轻载和电源吸收能力。不能只看标称22µF。
2. 控制VA5下降斜率及注入快速掉电，记录VA5、RESET、ARMED、RUN_OK和实际六路栅极。要求实际关断在ADC退出有效工作区前完成；以最坏总延时与最快下降斜率验证58.519mV预算是否足够，不满足则增加保持时间或改保护架构。
3. 验证VIO、VA5和12V任意上/下电次序、半供电、慢斜坡、反复欠压、CLEAR与故障竞争、恢复不会自动重启。验证C94容差/漏电/温度下的最短恢复时间及CLEAR协议。
4. 按系统定义确认ADC零点校准、OCP误差、编码器供电范围、寿命漂移和采购料号；验证推荐焊盘、阻焊与钢网工艺。
5. 继续处理原审计其余问题，完成真实PCB布局布线、DRC零违规/零未连接及发布门禁。S01当前状态为“静态设计已修复，动态资格OPEN”；S09供电时序仍OPEN，其他项未整体关闭。
