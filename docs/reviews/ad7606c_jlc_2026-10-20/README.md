## 已修复的验证工具问题

1. 冻结设计遗漏 `fabrication_profile.json`，使制造意图规则读取不存在的输入。现在将其作为单独绑定的制造输入复制和哈希校验，继续将审核注册表排除在设计哈希之外，避免签核循环引用。
2. 制造意图规则使用系统默认编码读取 KiCad 文件，在 Windows GBK 环境失败；改为明确 UTF-8。
3. 常规验证哈希使用 Windows 反斜杠，而制造冻结哈希使用 POSIX 键，造成制造导出误报源变化；统一为便携键。

新增回归测试均先复现失败，再验证修复；保留所有安全、原生严重度和发布门禁。

统一 `fabrication-review` 命令在本机 KiCad 内置解释器缺少 pypdf 时明确失败，未被改成通过。已生成的原生 Gerber、钻孔、STEP、图纸和 BOM/CPL 通过独立 Python 流程另行检查；该流程使用已安装的 pypdf 和 Gerbonara API，记录其版本、输入和输出摘要。没有把此独立检查描述为统一导出命令成功，也没有伪造制造放行 ZIP。

## dc-link 页的明确变更边界

当前该页包含 C1/C2/C120–C127 十个 100 µF 电容、R120–R129 十条独立阻尼支路以及 J7 保护后母线接口。删除整个电路会改变储能、纹波和回馈接口；仅取消独立页面、将器件并入电源页则保持电气功能，两种操作不能混同。

在确认采用哪一种前，保留当前原生连接和 PCB。若取消整页器件，必须同步修改原理图、PCB、BOM、DC-link 配置/回归合同和外部母线要求，重新验证 RSH4 不被旁路、外部储能/吸能连接位置及关断状态。现有 C3/C4 的局部高频旁路不能直接宣称替代 1000 µF 母线电容组。若仅合并页面，要求修改前后物理引脚归属精确等价并重新查看图面。

本轮尚未完成这项硬件变更，因此上述 CAM 资料只用于当前保留 dc-link 的源设计审阅，不能作为删除后的制造文件。
