# 原理图优化 — AX7010 2022 / J10 与外置保险

用户确认 ALINX AX7010 2022 版、J10，并授权按推荐方案选保险；本轮仅修改原理图、检查、BOM 和说明，不同步或布局 PCB。保留分支 `fix/ocp-latch-industrial-review` 及所有已有未提交文件。

## 接口核验

对照 [ALINX 官方原理图目录](https://github.com/alinxalinx/AX7010_2023.1/tree/master/Hardware/01_SCH) 中 AX7010/AX7020 V2.0 文件第 5、15 页，视觉核对 J10 和 IO1 Bank 管脚。公开图纸标题栏日期为 2018-10-08，并非宣称已取得 2022 专用图纸。2022 实板身份来自用户确认，实物逐针通断和 Bank 电压仍需验证。

现有映射无需修改：1/37/38 地、2 为 5V 且本板 NC、39/40 为 VIO 3.3V，3..36 的 34 个信号脚映射与公开图一致。增加 J1 Board_Revision/Board_Connector 属性与活跃信号/供电脚安全回归，接口文档与 XDC 注释同步更新。辅助和 ENC_FAULT_N 等当前 NC 信号不因 XDC 预留而变成已连线。

## 保险选择与连接

推荐外置 **Littelfuse KLKD025.T**：25A、600VDC、10x38mm 熔断器；配 **LPSM0001Z** 单极非指示导轨座。位于电源正极靠近源端，保护到伺服板的线束；不能将未保护的长线先接板再在远端加保险。

厂家依据：[KLKD 数据手册](https://www.littelfuse.com/assetdocs/klkd-datasheet?assetguid=7b52eebb-c7cc-43df-a8da-9682a338e0f6)，2025-05-29，第 2 页额定、第 3 页订货、第 4 页电气数据和后续曲线；[Littelfuse 座产品目录](https://www.littelfuse.com/assetdocs/powr-gard-catalog?assetguid=d4b3148c-7de4-4106-be83-cebe03318781)，LPSM 系列 30A / 600VAC/DC，非指示单极 LPSM0001Z。所选 DC 耐压覆盖 55V 母线目标。应采用厂家规定装配扭矩、导线范围及环境降额。更高的额定电压不免除实际直流分断条件审核。

选择外置的工程原因是可维修、避免较大发热/夹持载荷占用 130x95mm 功率板、可在源端保护线束，并避开原未选型 2920 占位封装。25A 是当前设计初选，依据是既有 15A 连续/25A 短峰值目标；相电流不能直接等同于 DC 输入电流，不能声称已完成保险配合。

原理图明确 `J6.1 (PSU+) -> F1.1/2 -> VIN_FUSED -> J3.1 -> Q7/U18`，J6.2/J3.2 为 GND。J6 是外部电源接线边界，不是新增板载连接器，也不是已选定电源采购型号。F1/J6 均 `on_board no`、`in_pos_files no`，无 PCB 封装，保留在系统 BOM；F1 不是 DNP。F1 的 Holder_MPN 和 BOM 状态明确要求 LPSM0001Z，采购系统件时必须配齐此座。

不能将外置保险误解成完整功率保护：本地 DC-link 电容的放电故障电流不经过源端 F1；MOSFET/驱动/OCP 的动态保护仍必须独立工作。母线两个 100uF 电容仅其标称电容在 48V 已储能 0.2304J，在 55V 为 0.3025J；实际还含其他电容、容差及供电能量。输入浪涌、源限流、线束电流及环境降额、保险 I²t 和预期短路电流/时间常数要实测并对照厂家曲线。F1 不提供再生耗能或过压钳位；D1 仍 DNP，LM74502 OV 接低的现状保留为未关闭门禁。

## 修改和验证

原始快照与本轮证据：`artifacts/schematic_opt_2022/`；修改前硬件文件在 `before/`。保险及外部源端子在完整系统图中仍然连接，但 KiCad PCB 网表原生省略 off-board 对象。

- 系统图 / BOM：159 个对象（157 板载 + F1/J6 外部对象）。原 158 中的 F1 改为外部，新增 J6；不是删除保护电路。
- 新鲜 PCB 网表：157 元件 / 179 网络。外部 VIN_RAW 不进入板级网表，J3.1 现在直接为 VIN_FUSED。
- ERC：0 错误 / 0 警告 / 0 排除，未降低严重级别或增加忽略项。
- 原生结构、50mil 网格、A4 布局、层级连接、工程/BOM、安全网表、531 项 OCP 稳态场景及 11 项既有 PCB 检查器回归通过。
- 外部 F1 属性与 J3 输入连接的新增规则，已在旧设计上先观察失败，再验证新设计通过；没有以更新元件计数替代连接检查。
- 电源页 PDF/PNG 已渲染并视觉检查，清除了 Datasheet URL 覆盖接线的问题，端子/源侧导线移入边框。

PCB 文件 SHA256 与修改前相同。只读逐焊盘审计按预期失败：旧板额外 F1 一个、J3.1 网络不一致一个。此前 162 封装、271 DRC / 466 未连接 / parity 0 是旧同步阶段记录，不代表当前图板一致。未运行 PCB 布局布线、未发布制造资料。现有 CI 的图板一致性门禁也会保持失败直到用户允许后续同步，未屏蔽它。
